# ToDO-AKA

Офлайн-планировщик: задачи, проекты, метки, помидор и тайминг. Один интерфейс для телефона и компьютера. Данные сначала сохраняются на устройстве, а при появлении сети сходятся в аккаунт.

Тариф сейчас один: **BETA FREE**.

Имя репозитория не связано с товарным знаком Todoist. Похожи только привычные вещи: входящие, проекты и метки.

## Локально

```bash
npm install
npm run dev
```

Открой http://localhost:8080

## Render

1. Зайди на https://dashboard.render.com и войди через GitHub.
2. New → Blueprint. Укажи репозиторий `arsjulvorob8888/Todo-ist`. Render прочитает `render.yaml`.
3. После первого адреса сайта открой сервис → Environment и поставь `BETTER_AUTH_URL` = `https://твой-адрес.onrender.com` (без слэша в конце).
4. Manual Deploy ещё раз, чтобы адрес попал в сборку входа.
5. Открой сайт → Кабинет → создай аккаунт. Тот же аккаунт на телефоне и на компьютере синхронизирует задачи.
6. Вход через Google (Gmail): в [Google Cloud Console](https://console.cloud.google.com/apis/credentials) создай OAuth-клиент типа **Web application**. Authorized JavaScript origin: `https://poryadok-1xfe.onrender.com`. Authorized redirect URI: `https://poryadok-1xfe.onrender.com/api/auth/callback/google`. В Environment сервиса Render добавь `GOOGLE_CLIENT_ID` и `GOOGLE_CLIENT_SECRET`, сохрани и сделай **Manual Deploy**.

Бесплатный Render засыпает. Первый заход после паузы может занять около минуты. Пока сервер спит, приложение на уже открытом устройстве продолжает работать локально.

## Приём из «Кремля»

«Кремль» может присылать задачи и цели в «Порядок». Это односторонний канал: чего нет в очередном запросе, то в «Порядке» не удаляется и не сбрасывается.

`POST /api/integrations/kremlin`

Заголовок: `Authorization: Bearer <токен>`.

В Environment сервиса на Render задай две переменные. Сами значения в репозиторий не кладутся.

- `PORYADOK_INGEST_TOKEN` — секрет, с которым сравнивается токен. Сравнение постоянное по времени. Если переменная не задана, endpoint отвечает `503` и ничего не пишет. Нет заголовка или токен не совпал — `401`.
- `PORYADOK_OWNER_EMAIL` — почта единственного аккаунта «Порядка», в чей слот `sync_records` пишутся проект, задачи и цели. Сравнение без учёта регистра, пробелы по краям снимаются. Если переменная не задана — `503`, запись не делается. Если аккаунта с такой почтой нет (или почта совпала больше чем у одного) — `409`, запись не делается. Другие аккаунты не затрагиваются: нет общей, анонимной или «первой попавшейся» полки.

Один раз владелец входит в «Порядок» под этой почтой, чтобы строка пользователя появилась. После этого приём начинает писать в его слот, и данные доезжают на его устройства вместе с обычной синхронизацией. Локальные записи в `poryadok-v1` при этом не затираются: одинаковые `id` / `externalId` сходятся по более новому `updatedAt`.

Тело — JSON:

```json
{
  "source": "kremlin",
  "sentAt": "2026-11-17T10:00:00.000Z",
  "tasks": [
    {
      "externalId": "task-1",
      "title": "Проверить отчёт",
      "priority": "Срочно",
      "status": "В ожидании",
      "deadline": "2026-12-01",
      "description": ""
    }
  ],
  "goals": [
    {
      "externalId": "goal-1",
      "title": "Закрыть квартал",
      "description": "",
      "deadline": null,
      "kpis": [{ "name": "Выручка", "target": 100, "current": 40, "unit": "млн" }]
    }
  ]
}
```

`priority`: «Срочно», «Высокий», «Средний», «Низкий». `status`: «В ожидании», «В процессе», «Выполнено». `deadline` у задачи — ISO-дата или `null`. У цели `description` и `deadline` необязательны; если `deadline` прислан, он сохраняется (в том числе `null`). Размер тела до 256 КБ, не больше 500 задач и целей.

Задачи попадают в проект «Кремль»: проект создаётся, если его ещё нет, и переиспользуется, если уже есть. Повтор с тем же `externalId` обновляет поля, а не создаёт копию. У задачи, цели и проекта ставится `source: "kremlin"` — в интерфейсе они помечены красной полосой и значком «Кремль».

Ответ при успехе: `{ "ok": true, "created": 0, "updated": 0, "unchanged": 0 }`. Некорректное тело — `400`.

## App Store и Google Play

Сейчас это устанавливаемое веб-приложение. Для магазинов тот же интерфейс оборачивается Capacitor (конфиг уже лежит в `capacitor.config.json`):

```bash
npm install @capacitor/core @capacitor/cli @capacitor/ios @capacitor/android
npx cap add ios
npx cap add android
npm run build
npx cap copy
```

Дальше архив отдаётся в App Store Connect и Google Play Console. Нужны аккаунты разработчика Apple и Google.
